Arraytics / ThemeWinter · On-page SEO

Building an on-page SEO programme from scratch

ThemeWinter had plenty of pages and no way to tell which ones worked. So before rewriting anything, I built the way to measure it.

At a glance

  • Four layers, in order: audit, report, find the gaps, then fix.
  • A keyword database of about 1,010 terms from Google Keyword Planner.
  • A tag gap analysis to make the plugins easier to find on WordPress.org.

01 / 04

The problem

Blog posts, landing pages, product pages: all there. What wasn't there was any way to see which keywords they ranked for, or where they fell short.

Without a baseline you can't prioritise. Does this page need a rewrite, or a backlink? Nobody could say.

02 / 04

The plan

Measure first, write later.

  • Audit: document titles, meta descriptions, headings, keyword use and internal links on Eventin's pages.
  • Report: a blog ranking report and an on-page page report to track movement.
  • Gap: a pricing keyword gap analysis, showing high-intent searches competitors won and we didn't.
  • Fix: apply it, starting with the WordPress.org ranking push for WP Timetics.

Alongside that, a tag gap analysis: map every competitor's WordPress.org tags, split the common from the rare, and build a target list (events, calendar, schedule, tickets, event booking system, reservations and more).

03 / 04

What I did

  • On-page audit of Eventin's webpages.
  • ThemeWinter blog ranking report and on-page SEO page report.
  • Pricing keyword gap analysis.
  • An issues and keywords-to-rank sheet for WP Timetics on WordPress.org.
  • A keyword database for Timetics AI, from head terms like "appointment" and "booking" (500,000 searches a month each) down to long-tail ones like "booking system for small business" (500 a month, with $10.48–$45.36 top-of-page bids).
  • Eventin SEO landing page copy, built on the audit.
