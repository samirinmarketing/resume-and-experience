Building the On-Page SEO Programme

Not just writing optimised content. Building the measurement infrastructure: ranking reports, on-page audits, a pricing keyword-gap analysis, and a wordpress.org ranking push.

The Problem 01 / 04

ThemeWinter had content. Blog posts existed, landing pages existed, product pages existed. What didn't exist was any structured way to measure whether they were performing, which keywords they were actually ranking for, or where the gaps were between what the pages targeted and what users searched.

The deeper problem: without ranking data, there was no way to prioritise. The team couldn't distinguish between a page that needed a rewrite and one that needed a backlink, because neither performance baseline existed.

Strategy 02 / 04

Built the SEO programme in layers, starting with measurement before touching any content:

  • Layer 1, Audit: R&D on-page SEO analysis of Eventin's webpages. Documented current title tags, meta descriptions, header structures, keyword density, and internal linking patterns.
  • Layer 2, Reporting: Created a ThemeWinter Blog Ranking Report and an On-Page SEO Page Report to establish baseline rankings and track movement over time.
  • Layer 3, Gap analysis: Built a pricing keyword-gap analysis (spreadsheet) identifying where ThemeWinter's pricing pages were missing high-intent queries that competitors ranked for.
  • Layer 4, Execution: Applied findings to specific pages, with the wordpress.org ranking push for WP Timetics as the priority execution target. Built a keyword research database (~1,010 rows from Google Keyword Planner) for Timetics AI to support ongoing content decisions. The database covered terms from "appointment" (500,000 monthly searches) and "booking" (500,000) down to high-intent long-tail queries like "booking system for small business" (500 searches, $10.48-$45.36 top-of-page bids).

A parallel workstream used a tag-gap analysis for the wordpress.org plugin directory. By mapping each competitor's WordPress.org tags and separating common tags from uncommon ones, a target tag list was derived (e.g. events, calendar, schedule, organizer, tickets, event registration, event booking system, reservations, scheduling) to close gaps in plugin directory discoverability.

Execution 03 / 04

  • R&D on-page SEO audit of Eventin webpages, documenting current state across all key ranking signals.
  • ThemeWinter Blog Ranking Report establishing baseline positions.
  • ThemeWinter On-Page SEO Page Report for the product and landing page set.
  • Pricing keyword-gap analysis identifying missed high-intent queries on pricing pages.
  • Issues and keywords to rank document for WP Timetics on wordpress.org, targeting plugin directory search.
  • Timetics AI Keyword Research Database for ongoing content prioritisation.
  • Eventin SEO Landing Page copy, applying audit findings to a priority conversion page.
