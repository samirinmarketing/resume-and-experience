01 / 04

The problem

Two crowds, two worries. Existing users wanted to know what changed, and that their workflow would survive it. New users needed to see a modern plugin, not an old one with a new number.

02 / 04

The plan

Treat 4.0 as a campaign.

  • Launch blog: "Eventin 4.0 is Here", a walkthrough of what users gain, not a changelog dump.
  • v3 vs v4: the old boxes next to the new wizard. Support's reference, and upgraders' reassurance.
  • QA report: known issues and fixes, out in the open. No pretending day one was perfect.
  • Screenshots: the whole admin, for the readme and the docs site.
03 / 04

What I did

  • "Eventin 4.0 is Here" launch blog.
  • v3 vs v4 comparison with side-by-side screens.
  • QA report for the dev and support teams.
  • A full readme.txt rewrite for WordPress.org search.
  • 62 admin screenshots in three groups: UI walkthrough, tagged captures and code optimization visuals.
  • A founder post draft for the CEO.
  • Release email for existing users.
