A new homepage and a sharper WordPress.org listing

Eventin is a WordPress events plugin that does a lot: tickets, RSVPs, attendees, WooCommerce, even AI event creation. Its homepage listed all of that, and forgot to say why anyone should care.

At a glance

  • Homepage rewritten around the outcome: run better events, from calendar to checkout.
  • Readmes for 3 plugins rebuilt for WordPress.org search.
  • A tag gap analysis against competitors to pick the right tags.

01 / 04

The problem

The homepage led with features. The buyer, an event organiser, was really asking: how do I run events on WordPress without stitching five plugins together?

The WordPress.org listing had the same issue. That's where installs are won or lost, and a plugin that doesn't rank there doesn't get installed, however good it is.

02 / 04

The plan

Homepage: lead with the outcome, then group features in the order the job happens: create events, sell tickets, manage attendees.

WordPress.org: audit the readme against what plugin search rewards: short description keywords, long description structure, FAQ and screenshot captions. Then run a tag gap analysis on competitors to choose the tags.

03 / 04

What I did

  • Homepage copy for themewinter.com/eventin: hero, feature highlights, use cases and calls to action.
  • readme.txt rewrites for Eventin, WP Timetics and WPCafe.
  • For Eventin: a 150-character keyword-led short description, benefit-first features, a structured long description and an FAQ for pre-install questions.
  • Screenshot captions and changelog copy to keep the listing fresh.
  • A 2024 docs update across all three plugins, tracked in one shared sheet.
  • Later, the full Eventin 4.0 release campaign.
