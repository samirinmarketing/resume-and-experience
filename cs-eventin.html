The Problem 01 / 04

Eventin is a feature-rich WordPress event calendar and ticketing plugin, WooCommerce integration, RSVP management, attendee tracking, AI event creation. But its homepage copy was leading with features ("manage calendars, sell tickets, handle RSVPs") instead of the user's problem ("I need to run events on WordPress without cobbling together five plugins").

Simultaneously, the WordPress.org plugin repository listing, where thousands of potential installs are either won or lost, wasn't structured to capture the plugin's range of capabilities in the keyword-rich, benefit-first format that drives both rankings and install clicks.

A plugin that doesn't rank in the WordPress.org search doesn't get installed, no matter how good it is.

Strategy 02 / 04

Two parallel workstreams with different success metrics:

Homepage copy: Restructured the messaging hierarchy around the primary buyer, an event organiser who wants an all-in-one solution. Led with the outcome ("run better events, from calendar to checkout") rather than the feature set. Introduced capability clusters (create events → sell tickets → manage attendees) as a logical flow matching the user's actual job-to-be-done.

WordPress.org repository: Used a tag-gap analysis (mapping competitors' WordPress.org tags, separating common from uncommon, deriving a target set) alongside the readme audit against the WordPress plugin search algorithm's key ranking factors, short description keyword density, long description structure, FAQ section completeness, and screenshot descriptions. Mapped Eventin's core capabilities to high-volume plugin search queries.

Execution 03 / 04

  • Homepage copy rewrite: hero section, feature highlights, use case sections, and CTA copy for themewinter.com/eventin.
  • WordPress.org readme.txt rewrite for Eventin, WP Timetics, and WP Café, each optimised for their primary plugin category search queries.
  • Structured the Eventin readme with keyword-anchored short description (150 chars), benefit-led feature list, expanded long description with H2 sections, and an FAQ block targeting common pre-install questions.
  • Screenshot alt text and changelog copy to maintain fresh signals in the repository listing.
  • Cross-product documentation update programme (2024) covering Eventin, WPCafe, and WP Timetics simultaneously, tracked via a shared coordination sheet.
  • 62 annotated admin screenshots captured across the Eventin 4.0 release (May, Jun 2024), covering the full UI transition from legacy metabox to React wizard.
